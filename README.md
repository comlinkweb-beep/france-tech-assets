## Direct logo link (raw)
Once pushed to GitHub, open `assets/ftec-emblem-32.svg` and click **Raw**.
The URL will look like:
```
https://raw.githubusercontent.com/<your-user>/france-tech-assets/main/assets/ftec-emblem-32.svg
```

Use that URL in the Etherscan form under **“Link to download a 32x32 svg icon logo”**.
